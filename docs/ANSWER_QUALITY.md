# Проверка качества ответов

## Наборы проверок

- Unit/API-тесты проверяют обработку вопросов, контекст, права доступа, историю и контракты ответов.
- `evaluation.rag_eval` содержит9 сценариев выбора источников.
- `evaluation.answer_eval` содержит40 сценариев с ожидаемыми источниками, обязательными фактами, запрещёнными утверждениями и отказами при отсутствии данных.
- `tools.verify_project_onboarding` проверяет реальные локальные API, назначение и отзыв проектов, изоляцию данных и авторизацию. Ключ `--generate` добавляет проверку потока Ollama.

## Запуск

Из корня проекта:

```powershell
.\venv\Scripts\python.exe -m pytest tests -q
.\venv\Scripts\python.exe -m evaluation.rag_eval --output reports/rag_source_checks.csv
.\venv\Scripts\python.exe -m evaluation.answer_eval --output reports/answer_quality_latest.csv
.\venv\Scripts\python.exe -m tools.verify_project_onboarding --generate
```

Результаты сохраняются локально. Для новых прогонов задавайте отдельное имя CSV, чтобы не перезаписывать ручные оценки. Интеграционные проверки создают синтетические записи в откатываемой транзакции. Их следует запускать последовательно: параллельные транзакции могут ждать освобождения блокировок проектов. Облачная телеметрия в этих проверках отключена.

## Правила формирования ответов

Прямые инструкции MFA, отдельных инструментов и этапов обучения извлекаются из соответствующей документации. Явное описание технологического стека также извлекается из источника; упоминание технологии само по себе не считается подтверждением её использования. Недокументированные команды и версии не придумываются. Самостоятельные части составного вопроса обрабатываются отдельно с сохранением контекста и объединением источников.

Общие объяснения могут генерироваться локальной Ollama. Личные задачи, прогресс и заявки читаются по авторизованному пользователю из PostgreSQL и не добавляются в публичный RAG-корпус. В проектном режиме используются только документы разрешённого проекта.

## Ограничения

Успешная проверка источника не доказывает достоверность всех утверждений ответа. Проверки40 сценариев не являются универсальным измерением точности и не заменяют ручную оценку новых вопросов. Отдельно проверяются перефразировки, многошаговые диалоги, языки, вредоносные инструкции в документах и нагрузка. Быстрый ответ через извлечение нельзя использовать как оценку скорости свободной генерации.
